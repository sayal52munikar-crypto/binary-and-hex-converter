A small Python converter between binary, decimal and hexadecimal. Every conversion is written by hand, without bin(), hex(), format() or int(text, base).

Run
py bin_converter.py          # run the tests (6 milestones)
py bin_converter.py --menu   # interactive converter; type q to quit
Functions
1. binary_to_decimal / decimal_to_binary
2. binary_to_hex / hex_to_binary
3. hex_to_decimal / decimal_to_hex
